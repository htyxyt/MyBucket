# MyBucket Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build and publish a personal Scoop bucket with Markra and two ClipboardX variants.

**Architecture:** The repository is a standard Scoop bucket: manifests live under `bucket/`, documentation lives in `README.md`, and a local PowerShell test validates manifest shape. GitHub release URLs and SHA256 hashes are explicit in each manifest, while `checkver` and `autoupdate` provide future update support.

**Tech Stack:** Scoop manifest JSON, PowerShell validation, Git, GitHub SSH remote.
